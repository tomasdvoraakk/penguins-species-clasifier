# Penguin Species Classifier

My first machine learning project, built to learn how to prepare data, train a classification model, and evaluate its predictions.

## Goal

Predict a penguin’s species—Adelie, Chinstrap, or Gentoo—using four physical measurements:

- Bill length
- Bill depth
- Flipper length
- Body mass

## Dataset

This project uses the Palmer Penguins dataset, loaded through seaborn. The dataset contains 344 penguins; 342 remain after removing rows with missing measurements.

## Progress

- Loaded and inspected the dataset.
- Checked species counts and missing values.
- Selected the input measurements and target.
- Removed rows with missing measurements.
- Separated the inputs from the target.

## Next steps

- Split the data into training and test sets.
- Train a decision tree classifier.
- Evaluate its predictions and investigate mistakes.

## Tools

Python, pandas, seaborn, and scikit-learn.
